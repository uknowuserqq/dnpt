# Dnpt - APT to DNF Command Translation Utility

`dnpt` is a lightweight Python-based command-line wrapper designed to map Debian/Ubuntu `apt` commands directly to their Fedora/RHEL `dnf` equivalents. It allows system administrators and developers familiar with APT syntax to seamlessly operate in RPM-based Linux environments.

---

## Technical Overview

- **Command Mapping:** Transparently translates standard `apt` commands (`install`, `update`, `upgrade`, `remove`, `search`, `autoremove`) into their `dnf` equivalents.
- **Built-in Wrapper Options:** Includes wrapper-specific parameters (`--version`, `--logs`) to manage utility output and review activity.
- **Automated Setup:** Includes an `install.sh` script to verify dependencies, detect environment settings, and set up aliases or executable symlinks (`apt` -> `dnpt`).
- **Localization:** Supports multi-language console output configuration (English / Spanish).

---

## Prerequisites & Dependencies

- **Python 3.x:** Required to execute the core wrapper script.
- **Nerd Fonts:** Recommended for proper rendering of terminal icons and visual indicators in the CLI interface.

## Command Reference

### APT Translation Commands

These commands mimic traditional `apt` usage and translate directly into `dnf` operations:

| APT Source Command | Translated DNF Execution | Description |
| :--- | :--- | :--- |
| `apt update` / `dnpt update` | `dnf check-update` | Refresh local repository metadata |
| `apt upgrade` / `dnpt upgrade` | `dnf upgrade` | Upgrade all installed packages |
| `apt install <package>` | `dnf install <package>` | Download and install target package |
| `apt remove <package>` | `dnf remove <package>` | Uninstall target package |
| `apt purge <package>` | `dnf remove <package>` | Remove package and configuration files |
| `apt search <query>` | `dnf search <query>` | Query repositories for matching packages |
| `apt autoremove` | `dnf autoremove` | Remove orphaned dependencies |

### Dnpt Internal Options

These options are handled directly by `dnpt` itself rather than passed to `dnf`:

| Flag | Description |
| :--- | :--- |
| `dnpt --version` | Displays the current installed version of `dnpt`. |
| `dnpt --logs` | Displays execution history and audit logs generated by `dnpt`. |

## Installation

1. Clone or download the source repository.
2. Grant execution permissions to the installation script:

```bash
chmod +x install.sh
```

3. Execute the installer with elevated privileges:

```bash
sudo ./install.sh
```

---

## Usage

Once installed, you can execute commands using `apt` (via alias/symlink) or `dnpt`:

```bash
# Package management operations
apt update
apt install htop systemd-resolved

# Wrapper internal management
dnpt --version
dnpt --logs
```
